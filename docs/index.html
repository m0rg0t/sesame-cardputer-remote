CONNECTION

How the remote finds Sesame.

The firmware is designed for the original Sesame robot project ↗. It can connect directly to the robot’s default access point or use another 2.4 GHz network shared by both devices.

  1. 01

    Join a network

    The firmware tries Sesame-Controller first, then lets you choose another nearby 2.4 GHz network.

  2. 02

    Find the robot

    It resolves sesame-robot.local through mDNS. On the default access point, it can fall back to the gateway address.

  3. 03

    Send commands

    Pose, movement, and stop commands go to the robot’s local HTTP API.

CONTROLS

Keyboard controls.

WASD

Hold to move

W / ↑ forward · A / ← left · S / ↓ backward · D / → right

Release the movement key to send stop.
↵

Run the selected pose

Enter plays the countdown, then sends the selected pose command.

■

Stop

Space or the Cardputer’s Go button sends a stop command immediately.

N

Scan nearby access points and enter a password on-device.

INSTALL v0.1.0

Install through M5Apps.

  1. 1

    Download the v0.1.0 release package.

  2. 2

    Copy the BIN from the package to the Cardputer SD card.

  3. 3

    Open M5Apps → Installer → SD, select the BIN, and choose an application slot.
